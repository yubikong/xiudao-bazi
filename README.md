## 金口诀排盘

### 四课算法

- **地分**：用户点击选择（默认 = 时支）
- **人元**：月干遁地分（五子遁），`GAN[(月干idx*2 + 地分idx) % 10]`
- **月将**：支 = `(13 - 月支idx) % 12`；干 = `GAN[(月干idx*2 + 月将支idx) % 10]`
- **贵神**：以时支定昼夜（卯~申 昼阳贵，其余阴贵）；贵人位 = `tianYi[日干][阳贵|阴贵]`；神名索引 = 阳贵 `(df-gr+12)%12` / 阴贵 `(gr-df+12)%12`；贵神干 = `GAN[(日干idx*2 + 地分idx) % 10]`

### 验证样例

1994-09-29 03:22（甲戌年 癸酉月 戊午日 甲寅时），地分=寅：
- 人元 = 甲寅
- 贵神 = 甲寅青龙（戊日阴贵未起，逆数到寅）
- 月将 = 丙辰天罡（酉月将辰）
- 地分 = 寅（东北）

### 地分切换

- 点击四课表中的**地分格**：循环切换到下一地支
- 点击下方**12地支按钮**：直接选

切换后即时重排金口诀四课 + 71 神煞。

## 紫微斗数排盘

### 核心算法

- **命宫** = `(1 + M - H) % 12`（寅起正月顺数到月，从该宫起子时逆数到生时）
- **身宫** = `(1 + M + H) % 12`
- **命宫干支**：五虎遁（年干→寅月干）
- **五行局**：命宫纳音五行（2/3/4/5/6 局）
- **紫微星** = `(2 + floor((day-1)/局)) % 12`
- **天府星** = `(4 - 紫微 + 12) % 12`
- **紫微星系**（逆排）：紫微、天机、太阳、武曲、天同、廉贞
- **天府星系**（顺排）：天府、太阴、贪狼、巨门、天相、天梁、七杀、破军
- **辅星**：左辅（辰+月-1）、右弼（戌-月+1）、文昌（戌-时）、文曲（辰+时）、天魁天钺（=天乙贵人）、禄存擎羊陀罗、火星铃星、地空地劫、天马（=驿马）
- **四化**（年干）：甲廉贞禄破军权武曲科太阳忌 等 10 天干
- **大限**：五行局数起运，阳男阴女顺行、阴男阳女逆行

### 十二宫

命宫起逆排：命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役、官禄、田宅、福德、父母

### 验证样例

1994-09-29 03:22 男命：
- 命宫辛未、路旁土、土五局、紫微午、天府戌、身宫亥
- 四化（甲年）：廉贞化禄（丑）、破军化权（巳）、武曲化科（卯）、太阳化忌（辰）
- 身宫在亥（官禄位）
- 大限：5 岁起运，阳男顺行
